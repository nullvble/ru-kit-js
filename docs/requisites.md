# Проверка реквизитов

## Результат проверки

Все функции `validate*` возвращают объект одного вида:

```ts
type ValidationResult<Details> =
  | { valid: true; value: string; details: Details }
  | { valid: false; error: ValidationErrorCode; message: string };
```

- `value` — нормализованное значение: пробелы, дефисы и точки удалены (`'112-233-445 95'` → `'11223344595'`).
  Сохраняйте в базу именно его.
- `error` — код для логики: `empty`, `invalid_characters`, `invalid_length`, `invalid_format`, `invalid_checksum`.
- `message` — текст на русском, готовый для показа под полем формы.

```ts
const result = validateInn(form.inn);
if (!result.valid) {
  errors.inn = result.message; // «ИНН должен содержать 10 или 12 цифр»
} else {
  company.inn = result.value;
  company.type = result.details.kind; // 'legal' | 'individual'
}
```

Для простых проверок есть короткие функции `isValid*`, которые возвращают `boolean`.

## Что именно проверяется

| Реквизит | Длина | Алгоритм |
|---|---|---|
| ИНН организации | 10 | контрольная цифра: сумма с весами 2, 4, 10, 3, 5, 9, 4, 6, 8, остаток от деления на 11, затем на 10 |
| ИНН физлица / ИП | 12 | две контрольные цифры по тому же принципу |
| ОГРН | 13 | первые 12 цифр как число: остаток от деления на 11, затем на 10 |
| ОГРНИП | 15 | начинается с 3; первые 14 цифр: остаток от деления на 13, затем на 10 |
| СНИЛС | 11 | сумма цифр с весами 9…1, остаток от деления на 101 (100 → 00); номера до 001-001-998 не проверяются |
| КПП | 9 | только формат: 4 цифры, 2 цифры или заглавные латинские буквы, 3 цифры |
| БИК | 9 | только формат: цифры, первая — 0 |
| Расчётный счёт | 20 | ключ из 3 последних цифр БИК и счёта, веса 7, 1, 3, сумма кратна 10 |
| Корсчёт | 20 | ключ из «0», 5–6 цифр БИК и счёта; у счетов `301…` последние 3 цифры равны концу БИК |

> Контрольная сумма доказывает только то, что в номере нет опечатки. Существует ли организация,
> можно узнать лишь по ЕГРЮЛ/ЕГРИП (например, через API ФНС или DaData).

## Генераторы тестовых данных

```ts
import { generateInn, generateBankAccount, generateBik } from 'ru-kit-js';

generateInn();                         // ИНН организации
generateInn({ kind: 'individual' });   // ИНН физлица
const bik = generateBik();
generateBankAccount(bik);              // счёт, который пройдёт проверку с этим БИК
generateBankAccount(bik, { prefix: '40817810' }); // счёт физлица в рублях
```

Чтобы тесты были воспроизводимыми, передайте свой генератор случайных чисел:

```ts
import seedrandom from 'seedrandom';
const random = seedrandom('fixtures');
const inn = generateInn({ random }); // каждый запуск — одно и то же значение
```

Сгенерированные номера случайны, но могут совпасть с реальными. Используйте их только в тестах.
