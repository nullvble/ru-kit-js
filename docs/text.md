# Тексты, числа и телефоны

## Склонение после чисел

В русском языке у слова после числа три формы: «1 товар», «2 товара», «5 товаров».
Встроенный `Intl.PluralRules` подсказывает категорию, но сами формы всё равно приходится
выбирать вручную. `plural` делает это за вас:

```ts
plural(n, ['товар', 'товара', 'товаров']);
formatCount(n, ['день', 'дня', 'дней']); // '21 день', '22 дня', '25 дней'
```

Порядок форм: для 1, для 2, для 5. Для дробных чисел используется вторая форма («1,5 часа»).

## Сумма прописью

`amountInWords` пишет сумму так, как принято в счетах, актах и договорах: прописью с
заглавной буквы, копейки цифрами.

```ts
amountInWords(15_000);       // 'Пятнадцать тысяч рублей 00 копеек'
amountInWords('1 234,56');   // строка с пробелами и запятой тоже подходит
amountInWords(99.9, { minor: 'words' });   // 'Девяносто девять рублей девяносто копеек'
amountInWords(42, { minor: 'none', capitalize: false }); // 'сорок два рубля'
```

Суммы считаются в целых копейках через `bigint`, поэтому ошибки плавающей точки
(`0.1 + 0.2`) не влияют на результат. Если копеек больше двух знаков, они округляются.

Встроенные валюты: `RUB`, `USD`, `EUR`, `CNY`. Для другой валюты передайте описание:

```ts
const KZT = { major: ['тенге', 'тенге', 'тенге'], majorGender: 'masculine', minor: ['тиын', 'тиына', 'тиынов'], minorGender: 'masculine' } as const;
amountInWords(3.03, { currency: KZT }); // 'Три тенге 03 тиына'
```

`numberToWords` переводит в слова любое целое число до 10²¹ и учитывает род:
«одна тысяча», «одно окно», «две копейки».

## Телефоны

`parsePhone` понимает все привычные записи номера (`8 (916) …`, `+7 916 …`, `916…`) и
возвращает его в формате E.164 вместе со страной и типом. У России и Казахстана общий код +7:
номера `+7 6xx` и `+7 7xx` — казахстанские.

Храните номера в формате `normalizePhone` (`+79161234567`), а показывайте через `formatPhone`.
Для логов и экранов подтверждения есть `maskPhone`.

## Транслитерация

| Схема | Для чего | Пример: «Юлия Щербакова» |
|---|---|---|
| `simple` (по умолчанию) | URL, имена файлов, логины | `Yuliya Shcherbakova` |
| `passport` | как в загранпаспорте РФ (ICAO Doc 9303) — для билетов и бронирований | `Iuliia Shcherbakova` |
| `gost` | ГОСТ 7.79-2000, система Б — библиография, однозначный обратный перевод | `Yuliya Shherbakova` |

`slugify` строит из заголовка адрес страницы: транслитерация, нижний регистр, только латиница,
цифры и разделитель. Параметр `maxLength` обрезает строку по границе слова.

## ФИО

`parseFullName` разбирает строку на фамилию, имя и отчество. Он понимает оба порядка
(«Иванов Иван Иванович» и «Иван Иванович Иванов»), тюркские отчества («Гасан оглы»)
и нормализует регистр. `formatInitials` формирует «Иванов И. И.» для документов и подписей.
С параметром `nbsp: true` используются неразрывные пробелы, чтобы инициалы не отрывались от фамилии.

`detectGender` определяет пол по отчеству, а без него — по окончанию фамилии. Если
определить нельзя («Ким», «Шевчук»), возвращает `undefined`.
